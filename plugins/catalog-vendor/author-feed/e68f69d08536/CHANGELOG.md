# Changelog

## 0.1.1

Adds the `bluesky-posts` skill. It tells the model to find the Bluesky tools with tool_search before web_search. It does not set requires_toolsets, so it stays in the model's skill list when Tool Search is left at its default, which hides this plugin's tools.

A handle in any letter case, with a leading @, or with fullwidth digits is accepted and sent in lowercase. A DID keeps the letter case of its identifier. Extra arguments, an empty actor, and a numeric actor are refused with a fix and an example, and the caller's value is not copied into the message.

The first sentence Tool Search shows now uses the words a person would ask with. A sentence that starts by describing the mechanism is not found, and the model falls through to the built-in web_search.
