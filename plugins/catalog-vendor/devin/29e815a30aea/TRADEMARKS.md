## Duckwork Agent and Fordex

[Duckwork Agent](https://github.com/DuckMind/duckwork), its name and marks
belong to [Fordex](https://fordex.com).

The README's bundled Duckwork mark is the image previously used by this project,
from this [published Duckwork mark](https://github.com/user-attachments/assets/ac2f5702-c842-4b2e-9340-737481fa0ece).
It is stored at `assets/branding/duckwork-mark.jpg`. The Desktop plugin uses the
Duckwork badge supplied by the host app.

## Devin and Cognition

[Devin](https://devin.ai), the Devin CLI and the trioexagon mark belong to
[Cognition](https://cognition.ai).

The SVG shape comes from the [official Devin favicon](https://devin.ai/favicon.svg).
The README's `assets/branding/devin-mark.svg` and `devin-mark-dark.svg` use the
same shape as the bundled Desktop icon, with a trimmed view box and contrasting
fills for light and dark themes. The shape is unchanged.
