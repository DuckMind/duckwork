# TinyFish installed

**Next:** route Duckwork' web tools to TinyFish and verify your key:

```bash
duckwork tinyfish setup
```

No key yet? Create one at [agent.tinyfish.ai/api-keys](https://agent.tinyfish.ai/api-keys?source=duckwork) — Search and Fetch are free. `setup` will ask for it.

Check anytime with `duckwork tinyfish doctor --live` or `/tinyfish-status` in a session.
