# Changelog

## 1.0.0

- First release for Duckwork: Agent Plugins v1 package with four skills (`hypd-getting-started`, `hypd-tools`, `hypd-overview`, `hypd-workflows`).
- Covers Google Ads, Meta (Facebook) Ads, Microsoft Ads, LinkedIn Ads, Google Analytics (GA4), Search Console and Merchant Center.
- Connects to `https://mcp.hypd.ai/mcp` through pinned `mcp-remote@0.1.49` over stdio, which handles OAuth.
