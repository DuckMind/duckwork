duckwork-telemetry is a plugin for [Duckwork Agent](https://github.com/DuckMind/duckwork).
It captures real usage data from the runtime, persists it to a local SQLite database, and
enforces budget limits: a hard breach blocks further tool calls, and a breach of a cron job's own budget pauses that job.
