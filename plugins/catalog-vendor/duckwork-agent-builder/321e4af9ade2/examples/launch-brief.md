# Duckwork Agent Builder — release brief

Product: Duckwork Agent Builder
Release: 1.0.0
Audience: people who use Duckwork Desktop and want assistants tailored to recurring work.

Included in this release:
- Duckwork Agent Builder lives in the native BOTS workspace, with no Sessions sidebar entry.
- A short conversation that asks relevant questions about the user's needs.
- Generated, editable specialist instructions and conversation starters.
- Refinement with version snapshots and side-by-side trials on the same task.
- Text reference files, including briefs, style guides, and examples.
- A live trial chat using Duckwork's existing model connection.
- Saving a specialist as a separate Duckwork Bot profile with its own memory and canonical Bot Chat.
- A Builder companion bot for conversational drafting, alongside the visual builder.
- A library of agent drafts and saved specialists.
- A unified plugin package and Python installer for macOS and Windows.

Scope:
- Building an agent configures an existing model; it does not train a new one.
- Trial chat uses instructions and reference files. Connected tools run in the saved agent.
- The package is free to inspect and modify under the MIT license. Model usage follows the user's provider.
- Native macOS validation is available. Windows runtime validation has not been performed on a Windows machine.

Voice: clear, useful, warm, without hype. Preserve concrete facts. Never invent prices, benchmarks, integrations, launch dates, or operating-system test results.

Example of good work:
“Give your recurring work a dedicated assistant. Describe the job, answer a few questions, and shape the instructions. Try a real task before saving your specialist in Duckwork.”
