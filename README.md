# DuckWork

**Your AI-powered workspace.**

DuckWork is a cross-platform desktop application that brings AI assistants, tools, and workflows together in one unified workspace.

With **DuckMind CLI built in**, DuckWork combines an intuitive desktop experience with powerful AI agent capabilities, helping you move seamlessly from conversations to real execution.

## Features

- **Built-in DuckMind CLI** — DuckMind CLI comes integrated with DuckWork, bringing powerful AI agent capabilities directly into your desktop workspace.
- **AI Assistant** — Chat with intelligent assistants to solve problems, write, analyze, and execute tasks.
- **Agentic Workflows** — Delegate multi-step tasks to AI agents, from planning to execution.
- **Tool Integration** — Connect AI agents with tools, services, and development environments.
- **Conversation Management** — Organize conversations, maintain context, and revisit previous work.
- **Desktop Experience** — A streamlined interface designed for everyday productivity.
- **Flexible Configuration** — Customize AI models, providers, and workflows.

## Powered by DuckMind CLI

DuckWork integrates **DuckMind CLI** as its core agent execution engine, combining the flexibility of a command-line AI agent with the convenience of a graphical desktop application.

Work with AI agents through a unified interface without needing to manage a separate CLI installation.
